# Spec 001: Slack Channel Tools

## Problem

Hermes Slack adapter implements `reactions_add`, `reactions_remove`, `chat_update`,
`conversations_replies`, `files_upload_v2`, and more — but none of these are exposed
as LLM-callable tools. The agent literally doesn't know it can use them.

## Solution

Create `tools/slack_tool.py` following the exact pattern of `tools/discord_tool.py`:
- Single tool registration (`slack_channel`) in the `slack` toolset
- Action-based dispatch via `_ACTIONS` dict
- Direct Slack Web API calls via `urllib.request` (no adapter dependency)
- Config-based action allowlist at `slack.channel_actions`

## Pattern (from discord_tool.py)

```
1. _ACTIONS dict: action_name → handler function
2. _ACTION_MANIFEST: (name, signature, description) for schema generation
3. _REQUIRED_PARAMS: per-action param validation
4. _build_schema(): generates OpenAI tool schema from manifest
5. Handler functions: each makes one Slack Web API call, returns formatted result
6. registry.register(): name, toolset, schema, handler, requires_env
```

## Actions

### Tier 1 — High value, existing adapter support

| Action | Slack API Method | Params | Notes |
|--------|-----------------|--------|-------|
| `react` | `reactions.add` / `reactions.remove` | channel, timestamp, emoji, action=add\|remove | Emoji name without colons |
| `edit_message` | `chat.update` | channel, ts, text | Can only edit bot's own messages |
| `delete_message` | `chat.delete` | channel, ts | Can only delete bot's own messages |
| `fetch_messages` | `conversations.history` | channel, limit?, latest?, oldest? | Returns recent messages |
| `thread_replies` | `conversations.replies` | channel, ts, limit? | Fetch thread contents |
| `upload_file` | `files.uploadV2` | channel, content, filename, title? | Upload text/file content |

### Tier 2 — Channel management

| Action | Slack API Method | Params | Notes |
|--------|-----------------|--------|-------|
| `set_topic` | `conversations.setTopic` | channel, topic | Needs channels:manage scope |
| `set_purpose` | `conversations.setPurpose` | channel, purpose | Needs channels:manage scope |
| `list_pins` | `pins.list` | channel | Needs pins:read scope |
| `pin_message` | `pins.add` | channel, timestamp | Needs pins:write scope |
| `unpin_message` | `pins.remove` | channel, timestamp | Needs pins:write scope |

### Tier 3 — Discovery/info

| Action | Slack API Method | Params | Notes |
|--------|-----------------|--------|-------|
| `list_channels` | `conversations.list` | limit? | Bot's channels only |
| `channel_info` | `conversations.info` | channel | Topic, purpose, member count |
| `user_info` | `users.info` | user | Display name, status, timezone |
| `list_users` | `users.list` | limit? | Workspace members |

### Handler example

```python
def _react(channel: str, timestamp: str, emoji: str,
           action: str = "add", **kw) -> str:
    endpoint = f"reactions.{'add' if action == 'add' else 'remove'}"
    result = _slack_request("POST", endpoint, {
        "channel": channel,
        "timestamp": timestamp,
        "name": emoji,  # without colons
    })
    return f"{'Added' if action == 'add' else 'Removed'} :{emoji}: reaction"
```

## Slack App OAuth Scopes to Add

Go to api.slack.com → App → OAuth & Permissions → Scopes → Add:
- `channels:manage` — set topic/purpose
- `pins:read` — list pins
- `pins:write` — pin/unpin
- `reactions:read` — list reactions on messages

Current scopes (keep): `app_mentions:read`, `channels:history`, `channels:read`,
`chat:write`, `files:read`, `files:write`, `groups:history`, `groups:read`,
`im:history`, `im:read`, `im:write`, `users:read`

After adding scopes, reinstall the app to the workspace.
